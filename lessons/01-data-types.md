# What kind of fact is this?

The type decides which math is legal.

| Type | Example | You may | You may not |
|---|---|---|---|
| Nominal | Color: red, blue, green | Count, check equal | Sort, subtract, average |
| Ordinal | Medal: bronze, silver, gold | Sort | Treat the gap between medals as a number |
| Interval | Celsius | Subtract | Say 20° is twice 10° |
| Ratio | Height, money, age | Subtract, multiply, take ratios | Treat 0 as anything but none |

Discrete means separate chunks you can count, such as number of siblings. Continuous means a smooth ruler, such as height. An ID number looks numeric and is nominal. Averaging student IDs is nonsense.

Record data is an ordinary table. Document data is text turned into word weights. Transaction data is a basket with no fixed columns. Graph data is dots connected by lines. Ordered data cares about sequence: a sentence, a DNA string, rain over days.
