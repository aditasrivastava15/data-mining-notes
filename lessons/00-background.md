# Words you need first

An object is one thing: one student, one house, one email. An attribute is one fact about it: age, price, number of exclamation marks. A data set is a table. Each row is an object. Each column is an attribute. Feature, variable, and field mean the column.

The class, label, or target is the column you wish you knew in advance. "Spam or not." "Sale price." If that column is missing and you want groups, you cluster. If it is a category, you classify. If it is a number, you regress.

The mean of 2, 4, and 6 is (2 + 4 + 6) / 3 = 4. It is the balance point. Variance is the average of (point minus mean) squared. The square root of variance is the standard deviation. Squaring matters because a point 3 below and a point 3 above would cancel if you only subtracted.

A straight line is y = mx + b. m is the slope: if x grows by 1, y grows by m. b is the intercept: the y you get when x is 0.

Probability is a number from 0 to 1: how often something happens if you repeat the situation. If 30 of 100 emails are spam, P(spam) = 0.3. If 20 of those 30 contain "winner," P(winner | spam) = 20/30. The bar means "if we already know."

Euclidean distance is the straight-line ruler: subtract coordinates, square, add, square root. Manhattan distance adds the absolute differences, like walking city blocks.

A dot product multiplies matching positions and adds. [1, 2] dot [3, 4] = 11. Large and positive means the lists point the same way. Cosine similarity is that agreement after you ignore length.
